# 🎓 Technical Placement Master Resource
### The Complete Zero-to-Hero Guide for interviews (TCS NQT, FAANG, Product Companies)

Welcome to the ultimate repository for technical and aptitude placement preparation. This repository contains exhaustive, modular, and interview-focused markdown guides covering everything from mathematical aptitude to advanced database architecture.

---

## 📂 Repository Structure

### 1. 🧮 TCS NQT Aptitude (`/TCS_NQT_Aptitude`)
A complete mathematical and logical reasoning masterclass. Every file includes formulas, 7 unique solving methods, time-saving tricks, and TCS NQT-level MCQs (Easy, Medium, Hard).
*   Percentages, Averages, Ratio & Proportion.
*   Time & Work, Time Speed Distance, Train Problems.
*   Number System, Probability, Permutation & Combination.
*   Mixtures & Alligations, Boats & Streams.

### 2. 💻 C++ Mastery (`/CPP`)
From core mechanics to the Standard Template Library (STL).
*   **Basics:** Syntax, Pointers, Memory, Variables.
*   **STL:** Vectors, Maps, Sets, Queues, Deques.
*   **Problem Patterns:** Essential algorithms implemented in Arrays, Strings, Numbers, and HashMaps (With & Without STL).
*   **OOP Deep Dive:** The 4 Pillars, V-Tables, Virtual Inheritance, and Smart Pointers (using the "Simba" analogy).

### 3. ☕ Java & DSA Zero-to-Hero (`/Java_DSA`)
The complete Java curriculum designed to obliterate interviews.
*   **Phase 1 (Basics):** Primitives vs References, Pass-by-Value Traps, method overloading, 1D/2D Arrays.
*   **Phase 2 (Strings & OOP):** String Immutability, `StringBuilder`, `==` vs `.equals()`, and full Java OOP concepts.
*   **Phase 3 (Advanced Core):** Exception Handling, Multithreading & Concurrency (Deadlocks, Volatile, Synchronized), Generics (`<T>`), File I/O & Serialization.
*   **Phase 4 (Modern Java):** Streams API (`map/filter/reduce`), Lambdas, JVM Internals, and the Mark & Sweep Garbage Collector.

### 4. 🗄️ DBMS & SQL Complete Guide (`/DBMS_SQL`)
The ultimate theoretical and practical database manual.
*   **DBMS Core Concepts:** ER Diagrams, Primary/Foreign Keys, Normalization (1NF → BCNF), ACID Properties, and Transaction Locks.
*   **SQL Mastery:** DDL/DML, Aggregate Functions, GROUP BY/HAVING, INNER/LEFT/FULL JOINS, Constraints, Views, and Window Functions (`ROW_NUMBER()`).
*   **Strategy & Practice:** Topic priority lists and classic technical interview SQL scenarios (e.g., 2nd Highest Salary, Anti-Joins).

### 🚀 How to Use This Repository
1. Navigate to the relevant folder you are currently studying.
2. Read the Markdown (`.md`) files in chronological order (01, 02, 03...).
3. Copy the code snippets and run them locally to verify.
4. Attempt the "5 Test Cases" and Practice Questions provided at the bottom of the technical modules!
